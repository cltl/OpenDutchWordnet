This is a simple editor for the Open Durch Wordnet and Referentie Bestand.
You can use this editor as a stand-alone program on a local XML on your computer, as follows:

* Start the server from the command line using: ```python3 server.py```
* Launch the editor in the browser through: ```http://localhost:8080```
* Load the latest version of the lexicon: odwn_orbn_gwg-LMF_1.4.xml (see resources/odwn in this Github).
* Make your changes and save the XML to disk
